## 1. API Architecture & Global Conventions

Visnora exposes a structured RESTful JSON API implemented via Next.js Route Handlers (`apps/web/app/api/v1/...`).

### 1.1 Authentication & Tenancy Headers
Every authenticated request must provide:
- `Authorization: Bearer <supabase_jwt>` (or valid session cookie).
- `X-Organization-Id: <uuid>`: Target tenant context. Server verifies caller's active membership in this organization.
- `X-Visnora-Trace-Id: <uuid>`: Optional caller correlation ID (generated by server if omitted).

### 1.2 Uniform Response Envelope
All API responses adhere to a consistent JSON envelope:

#### Success Envelope (`200 OK`, `201 Created`):
```json
{
  "success": true,
  "data": { ... },
  "meta": {
    "traceId": "c9b2f1e4-8422-4a0b-bc11-9e8c3b4a2e5d",
    "timestamp": "2026-11-04T15:30:00.000Z",
    "pagination": {
      "page": 1,
      "limit": 25,
      "totalRecords": 84,
      "totalPages": 4
    }
  }
}
```

#### Error Envelope (`400`, `401`, `403`, `404`, `422`, `429`, `500`):
```json
{
  "success": false,
  "error": {
    "code": "QUOTA_EXCEEDED",
    "message": "Monthly prompt execution allowance reached. Upgrade plan to run additional prompts.",
    "traceId": "c9b2f1e4-8422-4a0b-bc11-9e8c3b4a2e5d",
    "details": [
      {
        "field": "promptRunsUsed",
        "issue": "Current count (100) equals monthly plan limit (100)."
      }
    ]
  }
}
```

## 2. API Endpoints Catalog

### 2.1 Organizations, Workspaces & Membership (Implemented in M1)

#### `GET /api/v1/organizations`
Returns organizations the authenticated user belongs to with role and member counts.

#### `POST /api/v1/organizations`
Transactionally provisions a new organization, owner membership, default workspace, and optional initial brand project.
- **Payload**: `{ "name": "Acme Marketing", "website": "https://acme.com", "orgType": "business", "countryCode": "IN", "billingEmail": "billing@acme.com" }`

#### `GET /api/v1/organizations/:id`
Returns detailed configuration and metadata for an organization.
- **RBAC**: Any active member of the organization.

#### `PATCH /api/v1/organizations/:id`
Updates organization details (name, website, orgType, billingEmail, countryCode).
- **RBAC**: `OWNER` or `ADMIN`.

#### `GET /api/v1/organizations/:id/members`
Returns all active members of the organization with user profiles and roles.
- **RBAC**: Any active member of the organization.

#### `POST /api/v1/organizations/:id/members`
Creates a secure tokenized invitation for a new team member.
- **RBAC**: `OWNER` or `ADMIN`.
- **Payload**: `{ "email": "collaborator@agency.com", "role": "MEMBER" }`

#### `PATCH /api/v1/organizations/:id/members/:memberId`
Updates a team member's role (`ADMIN`, `MEMBER`, `ANALYST`, `VIEWER`).
- **RBAC**: `OWNER` or `ADMIN`. (Cannot demote sole Owner).

#### `DELETE /api/v1/organizations/:id/members/:memberId`
Removes a member from the organization.
- **RBAC**: `OWNER` or `ADMIN`. (Cannot remove sole Owner).

#### `GET /api/v1/workspaces`
Returns all non-archived workspaces for the specified organization.
- **Headers/Params**: `X-Organization-Id` or `?orgId=...`

#### `POST /api/v1/workspaces`
Creates a new workspace container.
- **Payload**: `{ "name": "Growth Clients", "description": "Agency growth portfolio" }`

#### `GET /api/v1/workspaces/:id` & `PATCH /api/v1/workspaces/:id`
Retrieves or updates/archives a workspace.

#### `GET /api/v1/projects`
Returns projects for an organization, optionally filtered by `workspaceId`.

#### `POST /api/v1/projects`
Creates a new brand tracking project with normalized domain extraction.
- **Payload**: `{ "workspaceId": "...", "name": "...", "primaryWebsite": "https://example.com", "targetCountry": "IN" }`

#### `GET /api/v1/projects/:id` & `PATCH /api/v1/projects/:id`
Retrieves or updates/archives a project.

#### `GET /api/v1/invitations`
Returns pending invitations for an organization.
- **RBAC**: `OWNER` or `ADMIN`.

#### `GET /api/v1/invitations/:token`
Public verification endpoint returning organization preview, role, and expiration date.

#### `POST /api/v1/invitations/:token/accept`
Accepts an invitation, adding the authenticated user to the organization.

#### `POST /api/v1/invitations/:token/revoke`
Revokes a pending invitation.
- **RBAC**: `OWNER` or `ADMIN`.

#### `GET /api/v1/users/me` & `PATCH /api/v1/users/me`
Retrieves or updates the authenticated user's profile (`fullName`, `company`).

### 2.2 Brand & Competitor Management (Implemented in M2)

#### `GET /api/v1/brands`
Returns all active brand profiles for the specified organization and optional project.
- **Headers/Params**: `X-Organization-Id` or `?orgId=...`, optional `?projectId=...`

#### `POST /api/v1/brands`
Creates a brand profile with rich identity parameters and normalized domain.
- **Payload**:
```json
{
  "projectId": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "canonicalName": "Visnora AI",
  "domain": "visnora.com",
  "aliases": ["Visnora", "Visnora Intelligence"],
  "industry": "Marketing SaaS",
  "country": "IN",
  "productsServices": ["AI Search Visibility", "GEO Intelligence"],
  "brandKeywords": ["visnora", "ai visibility"],
  "targetAudience": "Marketers and SEO Agencies",
  "brandContext": "Leading generative engine optimization analytics platform...",
  "isPrimary": true

```

#### `GET /api/v1/brands/:id` & `PATCH /api/v1/brands/:id` & `DELETE /api/v1/brands/:id`
Retrieves, updates, or archives an individual brand profile.

#### `GET /api/v1/competitors`
Returns competitors tracked for a given project.

#### `GET /api/v1/competitors/:id` & `PATCH /api/v1/competitors/:id` & `DELETE /api/v1/competitors/:id`
Retrieves, updates, or archives a competitor entity.

### 2.3 Prompts Library & AI Suggestion Engine (Implemented in M2)

#### `GET /api/v1/prompts`
Returns tracked prompts for an organization and project with filtering.
- **Query Params**: `?projectId=...&category=...&stage=...&groupId=...&isActive=true&search=...`

#### `POST /api/v1/prompts`
Creates a new tracked prompt assigned to one of the 9 core buying categories.
- **Payload**:
```json
{
  "projectId": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "promptText": "What are the best AI visibility tracking platforms in 2026?",
  "category": "Brand Discovery",
  "stage": "CONSIDERATION",
  "targetProvider": "google-gemini",
  "targetModel": "gemini-3.8-flash",
  "targetLocale": "en-IN",
  "cadence": "DAILY"
}
```

#### `GET /api/v1/prompts/:id` & `PATCH /api/v1/prompts/:id` & `DELETE /api/v1/prompts/:id`
Retrieves execution history, updates, or archives a tracked prompt.

#### `GET /api/v1/prompts/groups` & `POST /api/v1/prompts/groups`
Manages prompt categorization groups.

#### `POST /api/v1/prompts/generate`
Uses brand positioning and competitor profiles to deterministically generate search queries across the 9 buying categories.
- **Payload**: `{ "projectId": "...", "count": 8 }`

#### `POST /api/v1/prompts/seed`
Loads initial benchmark prompts from the M0 dataset for rapid onboarding.
- **Payload**: `{ "projectId": "...", "count": 10 }`

### 2.4 AI Response Collection & Tracking Engine (Implemented in M2)

#### `GET /api/v1/tracking/estimate` & `POST /api/v1/tracking/estimate`
Calculates pre-run token usage estimates and exact cost in INR paise.
- **Params**: `promptCount=10&model=gemini-3.8-flash&enableGrounding=false`

#### `POST /api/v1/tracking/start`
Triggers an immediate tracking run across selected or all active prompts. Executes Gemini generation, records verbatim AI text, extracts mentions and citations, computes usage costs in INR paise, and triggers recommendation generation.
- **Payload**:
```json
{
  "projectId": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "promptIds": ["..."],
  "provider": "google-gemini",
  "model": "gemini-3.8-flash",
  "enableGrounding": false
}
```

#### `GET /api/v1/tracking/runs`
Lists historical tracking runs with token counts, costs in paise, and success/failed counts.

#### `GET /api/v1/tracking/runs/:id`
Returns complete run details including every prompt execution, verbatim AI response text, extracted mentions with sentiment confidence, and verified external citations.

#### `POST /api/v1/tracking/runs/:id/retry`
Retries failed prompts within a tracking run with error isolation.

#### `GET /api/v1/tracking/schedules` & `POST /api/v1/tracking/schedules`
Configures automated recurring evaluation cadences (`HOURLY`, `DAILY`, `WEEKLY`).

### 2.5 Analytics, Citations & Recommendations (Implemented in M2)

#### `GET /api/v1/analytics/visibility`
Calculates project-level AI Visibility Score (0-100 gauge), Observed Mention Rate (OMR), Sample Share of Voice (SSOV), Citation Rate, Average Position, and sentiment distribution.

#### `GET /api/v1/analytics/competitors`
Returns side-by-side comparative metrics between primary brand and competitors.

#### `GET /api/v1/analytics/citations`
Analyzes top cited domains, citation frequencies, and verified external reference URLs.

#### `GET /api/v1/analytics/trends`
Provides daily time-series historical data points for Recharts trend charts.

#### `GET /api/v1/recommendations`
Returns actionable, evidence-based GEO recommendations.

#### `PATCH /api/v1/recommendations/:id`
Updates recommendation status (`NEW`, `IN_PROGRESS`, `COMPLETED`, `DISMISSED`).

### 2.6 Module B: Ad Intelligence (Planned for M4)

#### `POST /api/v1/ad-intelligence/connections/oauth-start`
Initiates Google Ads or Meta Ads OAuth authorization redirect.
- **RBAC**: `OWNER` or `ADMIN`.
- **Payload**: `{ "platform": "GOOGLE_ADS", "projectId": "..." }`

#### `GET /api/v1/ad-intelligence/projects/{projectId}/insights`
Retrieves first-party campaign reporting data.
- **Query Params**: `startDate=2026-10-01&endDate=2026-11-01`.
- **Response**: Platform-reported impressions, clicks, spend (paise), conversions, and ROAS with explicit platform badges.

#### `POST /api/v1/ad-intelligence/public-search`
Queries permitted public ad transparency archives (e.g., Meta Ad Library).
- **Payload**: `{ "advertiser": "HubSpot", "country": "IN", "platform": "META" }`

### 2.5 Module C: ChatGPT Ads Intelligence

#### `POST /api/v1/chatgpt-ads/connections`
Securely saves customer OpenAI Ads API credentials.
- **RBAC**: `OWNER` or `ADMIN`.
- **Payload**:
```json
{
  "projectId": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "accountIdExternal": "act_openai_982341",
  "apiKey": "sec_..." 
}
```
*Note: The API route encrypts `apiKey` with AES-256-GCM before writing to database.*

#### `GET /api/v1/chatgpt-ads/projects/{projectId}/campaigns`
Fetches platform-reported ChatGPT ad campaigns and performance metrics for the authorized account.

### 2.6 Billing & Webhooks

#### `POST /api/v1/billing/checkout`
Creates a Razorpay subscription checkout session.
- **Payload**: `{ "planTier": "PRO", "billingCycle": "MONTHLY" }`
- **Response**: `{ "razorpaySubscriptionId": "sub_...", "keyId": "rzp_..." }`

#### `POST /api/v1/webhooks/razorpay`
Consumes signed Razorpay webhook notifications.
- **Headers**: `X-Razorpay-Signature: <hmac_sha256>`
- **Processing**: Verifies signature against `RAZORPAY_WEBHOOK_SECRET`, enforces idempotency via `webhook_events` table, and updates tenant entitlements.

## 3. Zod Request Validation Schemas (Example Code)

```typescript
import { z } from 'zod';

export const CreateTrackedPromptSchema = z.object({
  projectId: z.string().uuid(),
  promptText: z.string().min(5).max(1000),
  stage: z.enum(['AWARENESS', 'CONSIDERATION', 'DECISION', 'GENERAL']).default('CONSIDERATION'),
  topicTags: z.array(z.string().max(50)).max(10).default([]),
  targetProvider: z.enum(['google-gemini', 'openai']),
  targetModel: z.string().min(1).max(100),
  targetLocale: z.string().regex(/^[a-z]{2}-[A-Z]{2}$/, 'Locale must be formatted as ll-CC (e.g. en-IN)'),
  cadence: z.enum(['HOURLY', 'DAILY', 'WEEKLY', 'MANUAL']).default('DAILY'),
});

export const ConnectAdAccountSchema = z.object({
  projectId: z.string().uuid(),
  platform: z.enum(['GOOGLE_ADS', 'META_ADS', 'OPENAI_ADS']),
  accountIdExternal: z.string().min(3).max(100),
  credentialSecret: z.string().min(10), // API key or OAuth refresh token
});
```

## 4. HTTP Status Codes & Error Mapping

| HTTP Code | Error Key | Scenario |
| :--- | :--- | :--- |
| **200 OK** | - | Successful read or synchronous update. |
| **201 Created** | - | Entity successfully created. |
| **202 Accepted** | - | Background job queued (e.g., prompt execution). |
| **400 Bad Request** | `INVALID_INPUT` | Payload fails Zod validation. |
| **401 Unauthorized** | `AUTH_REQUIRED` | Missing, expired, or invalid session token. |
| **403 Forbidden** | `FORBIDDEN` | User role lacks permission or cross-tenant access attempted. |
| **404 Not Found** | `RESOURCE_NOT_FOUND` | Specified project, prompt, or connection does not exist. |
| **409 Conflict** | `CONFLICT` | Unique constraint violation (e.g., duplicate slug). |
| **422 Unprocessable**| `QUOTA_EXCEEDED` | Tenant prompt run allowance exhausted for billing cycle. |
| **429 Too Many Req** | `RATE_LIMITED` | Request rate limit exceeded. |
| **500 Internal Error**| `INTERNAL_ERROR` | Unhandled server exception (trace logged, sanitized message). |
